# RAG-помощник по планированию производства (n8n + Telegram)

Прототип ИИ-помощника для производственно-диспетчерского отдела горно-металлургического предприятия. Сделан в рамках ВКР «Система планирования производства (APS)». Сотрудник задаёт вопрос в Telegram, а бот отвечает по внутренним регламентам и указывает, из какого документа и фрагмента взят ответ.

## Как работает

**Workflow A - индексация базы знаний** (`workflow_indexing.json`)
Google Drive → скачивание документов → извлечение текста → разбиение на фрагменты по 1 200 символов с перекрытием 200 → запись в Google Sheets (лист KB: doc_name, chunk_id, текст).

**Telegram RAG Bot - ответы** (`workflow_telegram_bot.json`)
Telegram → нормализация вопроса и удаление стоп-слов → поиск 2 самых релевантных фрагментов по совпадению слов и фраз (порог 0,08) →
- если найдено достаточно, агент на gpt-4.1-mini отвечает только по этим фрагментам и добавляет блок «Источники» с doc_name и chunk_id;
- если нет, бот честно говорит, что в базе нет ответа;

→ каждый запрос и ответ пишется в лист Logs.

## База знаний (`knowledge_base/`)
6 демонстрационных документов: регламент планирования и контроля переработки концентрата, методика KPI, чек-лист качества данных, FAQ, шаблоны пояснения отклонений KPI и сводки рисков.

## Что показывает проект
- проектирование RAG-пайплайна без кода: индексация, поиск, генерация, логирование;
- ответы со ссылками на источники и отказ при отсутствии данных, чтобы модель не выдумывала;
- знание предметной области: план-факт, KPI, качество входных данных.

## Как развернуть у себя
1. Поднять n8n: [n8n Cloud](https://n8n.io) или бесплатно локально - `docker run -it --rm -p 5678:5678 n8nio/n8n`, затем открыть http://localhost:5678.
2. В n8n: Workflows → Import from File, импортировать оба JSON.
3. Подключить свои учетные данные: Telegram, OpenAI, Google Drive, Google Sheets.
4. Запустить Workflow A, чтобы проиндексировать документы, затем активировать Telegram RAG Bot.

## Что можно улучшить
Заменить поиск по словам на векторный (эмбеддинги + Supabase/Qdrant), чтобы бот понимал перефразированные вопросы.
